the owner approved the S630 manual and requested clearing the draft revision
history and starting at v1.0.

`_build/releases/chassis/S630/v1.0/S630-en-v1.0.pdf`, with standalone HTML,
validation and a page overview in the same folder. Generated files remain local
build artifacts. No website deployment is configured.

Release validation passed image/source hashes, page count and size, layout and
footer clearance, internal links, hardware chips, printed procedure headings,
shared reference copy and absence of internal draft notes. Additional inspection
confirmed v1.0 on every page and only the initial-release entry in the history.
