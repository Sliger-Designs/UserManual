# S640 v1.0 release approval

On November 2, 2026, a larger S640 page 12 illustration was requested,
followed by the same v1.0 revision reset and release preparation as S630.

Page 12 uses the existing larger-illustration layout and tighter vector framing
around the chassis, both side fan brackets and all illustrated screws. The
original bitmap is unchanged. The enlarged page was visually reviewed.

The S640 manual manifest records release approval and date. Its model-specific
revision history contains only `v1.0 / 2026-11-02 / Initial release`.

Build with `.venv/bin/python scripts/build_manual.py --model S640`.
The 23-page release PDF is
`_build/releases/chassis/S640/v1.0/S640-en-v1.0.pdf`, with standalone HTML,
validation and a page overview alongside it. Generated files remain local build
artifacts; website deployment is not configured.

The release passes image/source hashes, page size/count, layout and footer
clearance, links, hardware chips, printed headings, shared reference copy and
customer-copy checks. Additional inspection confirmed v1.0 on every page and
the single initial-release history entry. Cover and history were visually checked.
