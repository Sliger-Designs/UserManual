# Cover numbering, warranty page and top-view drawings (2026-11-06)

Manual review fixes for every manual (rackmount and SFF):

- **Page numbers:** the cover is unnumbered and "In this guide" is page 1. The contents list,
  "(page N)" cross-references and the PDF page labels use the same numbers. The PDF viewer labels the cover with
  the model name. The source layout started numbering on the cover only because of a limitation in the
  original design tool.
- **Warranty & support:** the small "SUPPORT AND SERVICE" subtitles are removed. One contact block
  remains, centred at the bottom of the page. The website, warranty-policy and email
  addresses are links, and the phone number is a `tel:` link.
- **Top-view clearance drawings:** the notes sit in a left column. The drawing's empty margins are
  cropped in the layout, not in the published image files, so the drawing fills the rest of the page.
