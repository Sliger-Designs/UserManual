# Security policy

Please report security problems privately, not in public issues: use **Report a
vulnerability** on this repository's **Security** tab (GitHub private vulnerability
reporting). Include what you found, where, and how to reproduce it.

This repository builds static manuals and a browser translation editor; it runs no
servers and stores no customer data. Relevant reports include credentials or private data
committed by mistake, ways to make a workflow run untrusted code with write access, and
ways for a crafted translation ZIP or issue to affect the repository or the published site.

For product support, contact orders@sliger.com.
