### Install the card

1. Remove the necessary slot covers. Select the motherboard slot and open its latch if fitted.
2. Align the card with the slot and rear opening. Seat it evenly until the latch engages, where applicable.
3. Secure the card's mounting bracket to the PCIe retention flange using the yellow-marked 6-32 screws **A**.
4. Cover unused openings with slot covers **F**, secured with screws **A**.

<p class="info-note" role="note">Check power-connector and cable-bend clearance with the chosen cooling, PSU and storage configuration.</p>
